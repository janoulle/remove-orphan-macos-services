# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could cause unintended deletion, privilege misuse, symlink traversal, path-boundary bypass, backup corruption, or command execution.

Use GitHub's private vulnerability reporting feature for this repository. Include:

- the affected commit or release;
- a minimal reproduction using disposable files;
- expected and actual behavior;
- potential impact and required privileges;
- a proposed mitigation, if available.

Do not test against another person's Mac or data. Do not include credentials, private manifests, usernames, or sensitive filesystem contents.

## Supported versions

Security fixes are provided for the latest release and the current default branch. This project has not undergone an independent security audit.
